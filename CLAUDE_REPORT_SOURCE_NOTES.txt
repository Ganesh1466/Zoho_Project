PROJECT OVERVIEW
----------------
Project name: LocalMind
Goal: A general-purpose AI assistant that runs locally on a laptop.
Primary model: Qwen2.5 3B Instruct, OpenVINO INT4.
Inference runtime: OpenVINO GenAI 2026.4.0.0.
Device used in the recorded runs: CPU.
Python environment: openvino-env, Python 3.14.3.
Web interface: web/index.html.
Local web server: web_chat.py, bound to 127.0.0.1:8765.
Terminal client: chat.py.
Native client: cpp_migration/main.cpp.

The existing INT4 model was retained. No model download, model replacement,
fine-tuning, or RAG corpus was used for the recorded runs.

Python/browser request flow:
Browser -> web/index.html -> web_chat.py -> LocalMindEngine ->
OpenVINO GenAI CPU pipeline -> local Qwen model -> browser response.

Python terminal request flow:
PowerShell -> chat.py -> LocalMindEngine -> OpenVINO GenAI CPU pipeline ->
local Qwen model -> terminal response and generation metrics.

C++ request flow:
PowerShell -> guarded C++ inference smoke executable -> OpenVINO GenAI
LLMPipeline on CPU -> local Qwen model -> streamed terminal response and
performance metrics.

KEY COMPONENTS
----------------
1. localmind.py
   - Loads the OpenVINO GenAI pipeline once per Python process.
   - Uses the local model and CPU by default.
   - Provides response metrics, including TTFT, TPOT, throughput, and token
     counts.
   - Maintains bounded conversation context with recent turns and selected
     earlier excerpts.
   - Uses the tokenizer end-of-turn token and a general-purpose assistant
     prompt.

2. chat.py
   - Interactive local terminal chat client.
   - Displays the selected model path and device after loading.
   - Accepts /help, /clear, and /exit.
   - Prints each answer and available performance metrics.

   PowerShell launch command:
   cd D:\Documents\Zoho_Project
   .\openvino-env\Scripts\python.exe .\chat.py --model .\qwen-3b-openvino-int4 --device CPU --max-new-tokens 128

3. web_chat.py and web/index.html
   - Local browser interface and HTTP API.
   - Browser conversations are kept separate; backend context is in memory.
   - The interface displays model/device status and generation speed.
   - Markdown is rendered in the browser.

4. cpp_migration/main.cpp
   - Simple one-prompt C++ application using the OpenVINO GenAI C++ API.
   - Loads the existing local model on CPU and prints the response.

5. cpp_migration/genai_sdk_check.cpp
   - Instrumented C++ smoke test used for the recorded native inference.
   - Records periodic process and system memory samples to a CSV.
   - Uses a 3 GiB available-RAM start threshold and a 1 GiB low-memory
     termination guard. These safeguards were left enabled and were not
     bypassed.
   - Uses CPU inference with two inference threads and a 32-token output cap.
